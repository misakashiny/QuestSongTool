# 下载中心：推荐、筛选、封面与试听（v20.2）

入口：主界面顶部「下载歌曲」。在「发现歌曲」页的分类按钮中选精选推荐、本周/月/年高评分、最新发布、认证谱师、排名曲目或随便听听。推荐无需关键词；它们使用网站精选、发布时间及好评排序，不使用个人账号或偏好画像。周/月/年按最近7/30/365天发布范围取高评分。分类排序固定并隐藏冗余排序下拉，普通关键词搜索可自选六种排序。

v20.1移除上述分类下拉，全部分类按钮直接展示，窄窗口自动换行。结果默认3列×7行，每页21首；用“列”和“行/页”调整到1至6列、1至15行，布局会记住。行数是每页数据行数，卡片区仍可上下滚动；列表视图使用同样的每页歌曲数。调整行列保留已有选择，切回第一页重新请求；之后翻页按新的页大小连续取数。

结果中的编号已取消，卡片复选框在播放按钮正上方，均32逻辑像素。两种视图共用可见区域画布；缩放不再重建整页CTk控件。

默认封面卡片，可切紧凑列表；点击封面或歌名查看详情，复选框只负责批量选择。独立圆形播放按钮控制试听。底部试听栏始终显示，浏览、翻页、筛选和切到任务/导入页不打断试听；切换播放歌曲、停止或关闭窗口结束自身试听。网站缺封面显示占位，缺试听禁用播放。试听为网站提供的音频片段，最多播放前30秒，可调整音量和拖动定位；不是完整歌曲或谱面演示。原主界面本地试听共用同一播放器，不叠加播放。短片段小于30秒按真实片段长度显示。

保存位置和批量下载位于共享底栏；下载任务页提供进度、取消、重试、打开目录与清除已结束记录。链接/编号与本地ZIP在独立导入页操作，共用底部保存位置。所有歌曲仍通过原有安全下载与解压队列入库。

## 筛选

点击「筛选」，四个标签页中修改草稿，再点应用；取消不改变已应用条件，重置只重置草稿。应用重新查询并清空跨页选择。分页保留选择，最多200首。

英文网站原名保留，并附中文注释：如“Tech（技术型，复杂切块与手腕走向）”“Standard（双手标准模式）”。场景说明舞台背景，数值说明NPS/排行榜星级含义。不限表示不参与该条件，包含表示必须具备，排除表示不能具备；中文显示名称不会改变发送给网站的标签/场景/模式ID。注释只帮助理解分类，不保证网站标注准确或模组兼容。

- 常规与扩展：人工/AI/全部、All/Ranked/BeatLeader/ScoreSaber、精选、认证谱师、完整难度分布、Chroma、Noodle Extensions、Mapping Extensions、Cinema、Vivify；开关支持不限/包含/排除。游戏模式包括Standard、OneSaber、NoArrows、90Degree、360Degree、Lightshow、Lawless、Legacy。
- 标签：网页的Style与Genre共45项；可以要求或排除，多项以AND组合。Dance风格与Dance音乐类型使用不同编号。
- 环境：网页Legacy与New环境共47项，多选以网站接口语义查询。不包括网站不展示的Multiplayer内部环境。
- 数值与日期：NPS、BPM、时长秒数、好评百分比、BeatLeader/ScoreSaber星级、投票数上下限；日期UTC、结束日期包含当天。空值不限；非法数字、颠倒上下限或日期在请求前拦截。与精选/认证推荐分类矛盾的排除条件会提示，需改分类或条件。

网页数据可能没有标注扩展/难度，不能据此宣称Quest或模组兼容性。筛选条件经网站接口执行，不仅过滤当前20首。下一页由原始条数推断，可能为空页；随机分页不保证无重复，下载仍按版本查重。

## 登录、限制与缓存

本轮无Cookie、Authorization或API密钥的公开请求实测：推荐/带筛选列表、封面、试听均HTTP200；曲包地址读取开头1024字节同为200，未入正式曲库。当前公开下载不需要登录；程序不保存网站密码，不提供账号登录、账号书签/关注或私人资源。

不能承诺无限制或固定每日额度：本次响应没有给出固定配额头，官方公开接口契约没有给出可通用承诺的日下载数。遇429按Retry-After等待并有限重试，最后显示网站限流；401提示网站要求身份验证，403提示拒绝访问，不绕过策略。封面批次遇拒绝/限流/连续网络失败会结束，重新查询可重试。

程序自身限制与网站额度不同：同时下载两首、跨页最多200首、历史500条；原ZIP大小/安全解压限制保留。封面单文件5MiB、最多4096×4096像素，缓存64张256×256缩略图；试听单文件16MiB、缓存3段，均仅当前窗口内存缓存。临时网络文件用后清理，关闭/退出会取消并等后台清理；不提前下载完整曲包来试听，不缓存账号数据。

官方依据：https://beatsaver.com/ 、https://api.beatsaver.com/docs/index.html 。标签和环境快照来自2026-10-17官网公开main.js（版本6d28b4d328f7）的数据项；未移植网站实现代码。后续网站新增分类时应刷新快照。

## v20.2筛选窗口操作

四个分类保留同一份草稿，切页不会清空。重置草稿不立即搜索；取消或关闭窗口不应用，应用筛选通过校验后才更新搜索。

下拉框、复选框和底部按钮可使用Tab定位并显示焦点；下拉框上下方向键切换选项，空格/Enter打开菜单；复选框空格切换。底部按钮的Enter/空格只作用于当前焦点，不新增全窗口Enter提交或Esc取消。选项仍保留官方英文名及中文解释。

验证边界：键盘菜单自动化确认按键到达原生弹出入口，Windows原生菜单实际显示与交互由用户视觉验收；完整27组结果见根目录04。
