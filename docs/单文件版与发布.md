# 单文件版与发布

本批日期：2026-10-29。对应版本20.4，保留现有Qt界面与业务。

## 使用

双击 `dist/QuestSongTool.exe`；发布下载见[GitHub Releases](https://github.com/misakashiny/QuestSongTool/releases)。EXE包含Python、PySide6/Qt、Pillow、miniaudio及ADB运行组件，不要求用户配置开发环境。默认进入曲库；`--downloads`直接进入下载页；`--lang en`与`--theme dark`可指定语言和主题。

运行数据继续保存在 `%LOCALAPPDATA%/QuestSongCompare-QtPreview/`。关闭后配置、评分、连接记录仍在；EXE与个人数据分别保存。单文件运行时会临时解出内部组件，第三方声明与原始许可文件也收集到包内。

## 目录与整理

业务和UI继续保留在`quest_tool/`，有效测试、夹具和基线保留在`tests/`。新打包文件集中于`packaging/`，构建脚本集中于`tools/`；原根目录的Tk打包配置移到`packaging/legacy/quest_tool_tk.spec`，并修正其根路径解析。旧Tk入口和共享模块不做未经依赖验证的删除。

已在删除前完整备份全部非Git文件。只清理可再生成的`__pycache__`和`tests/.tmp`；设置、数据库、下载记录、日志、运行报告、镜像与暂存原位保留。新增`push_staging/`忽略项，防止暂存歌曲进入源码仓库。

## 构建

- 脚本：`python tools/build_release.py`。
- 依赖：`packaging/requirements-build.txt`；本批使用已安装依赖，没有全局安装或升级。
- Android工具来源可用`--adb-source`指定，需含`adb.exe`、`AdbWinApi.dll`、`AdbWinUsbApi.dll`和`NOTICE.txt`。
- 默认输出`dist/QuestSongTool.exe`与`build-manifest.json`，中间文件默认`build/pyinstaller/`。
- 构建脚本隔离宿主PATH，防止混入其他软件的不兼容DLL；Qt使用Windows提供的ICU实现，避免误收集Poppler的同名库。
- `QUEST_CONSOLE=1`可构建诊断控制台版本；正式版本无控制台。当前EXE未作代码签名。

明确指定隔离目录后，可运行构建自检：

`QuestSongTool.exe --self-test-report <报告绝对路径> --data-dir <隔离数据目录>`

自检打开曲库、歌单、设备和下载窗口，检查图标、原生音频解码及内置ADB版本，然后正常关闭；不探测、连接或写入头显。自检资料与业务验收分别记录。
