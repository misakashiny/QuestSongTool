# Qt 歌曲收藏清单

时间：2026-10-24T18:46:41+08:00。状态：已实施、收藏专项通过；整体验收受音频不可用阻塞。正式APP_VERSION20.4/既有Qt阶段标记保持，本批不打包或发布版本。

## 使用方式

1. 下载页选中歌曲以显示右侧详情，右上角选项 → 收藏当前歌曲；菜单勾选表示已经收藏，再点一次取消。
2. 选项 → 收藏清单：按歌曲/艺术家/状态等现有表格文本搜索，查看收藏时的详情和已有缓存封面，可调用共享底部播放器试听/停止。
3. 在清单中选择行后点击加入已选，再在主页面按原流程下载。只加入当前选中行，搜索隐藏项不会自动加入；收藏本身不会自动勾选或下载。
4. 取消收藏只移除选中书签，不清除已有下载勾选，不删除歌曲。收藏保留至下次打开，下载勾选仍按原流程管理。

收藏入口不增加主页面常驻行，不改变九类入口、卡片编号/复选框、分页、详情CTA或播放器排版。样例模式/未启用独立下载运行目录的窗口不启用收藏。

## 组件与数据

FavoritesDialog继承原SelectedDialog，复用虚拟表格、搜索代理、详情、缓存图片和共享试听；FavoritesBrowser负责菜单、生命周期及加入选择，不新增试听引擎或下载队列。DownloadWindow仅在enable_downloads时传独立sandbox创建控制器，并接选择/翻译/图片刷新和关闭。

FavoritesStore固定文件qt-favorites-v1.json（独立Qt目录），版本1，仅保存Song字段快照，最多200首且2MiB。按小写十六进制BeatSaver编号去重；保存前验证40位哈希、现有safe_web_url的HTTPS/BeatSaver域名约束、有限有界数值、字符串/数组长度与UTF8编码。更新先读校验原文件再QSaveFile原子提交，拒绝链接目标、异常/未来版本/重复编号文件，失败保留原字节。当前选择优先保留较新的可见页或既有已选记录，不用收藏快照覆盖已有选择元数据。

保存的是历史信息，不保证网址永久有效、安装状态或当前发布版本不变；实际下载仍按编号由原队列重新解析当前版本。收藏窗口不主动为所有书签请求封面，缺失缓存时对应封面栏可能为空；不占用额外预加载通道。无云同步或账号登录。
