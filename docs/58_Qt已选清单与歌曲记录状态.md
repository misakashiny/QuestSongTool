## 状态含义及限制

| 显示 | 判断依据 |
| --- | --- |
| 排队/下载等进行中状态 | 当前保存目录、同一BeatSaver编号的活动任务 |
| 同版本下载记录 | 当前目录成功/已有任务记录的完整digest与歌曲digest匹配，可来自原ZIP历史 |
| 其他版本下载记录 | 同编号最近记录有不同digest |
| 最近失败/取消/中断 | 当前目录同编号最近终态记录 |
| 未核验安装状态 | 清单中没有可靠匹配记录；主卡片不显示“未安装”推断 |
