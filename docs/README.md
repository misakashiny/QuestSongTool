## 四、文档维护规则

1. **编号一律 `NN_中文名.md`**，新增文档取当前最大号 +1，**不跳号、不复用**；
2. **改了行为就改文档**：见 `../AGENTS.md` 第 5 节的同步表；
3. **不许写没验证过的结论** —— 凡是"已完成 / 实测通过"，必须带命令输出或数字；
4. 文件夹名与源码名保持英文（`quest_tool\`、`tests\`），只有**文档**用中文名。
