# 控件检查器（v20.4）

需重新启动源码程序，让Quest窗口获得键盘焦点。工具按程序内部Tk控件树工作，不是跨程序系统热键工具。

| 操作 | 效果 |
| --- | --- |
| Ctrl+Alt+I | 开关检查模式 |
| 鼠标悬停 | 显示完整控件的高亮、名称、类型和尺寸 |
| 点击 | 锁定控件，检查模式下不执行原按钮操作 |
| Tab / F2 | 切换浮层简略与详细，浮层可见时生效 |
| Ctrl+Alt+D | 打开完整属性窗口，可横竖滚动、选择文字及复制完整属性 |
| Esc | 取消锁定 |
| Ctrl+Alt+E | 沿用原导出JSON/Markdown入口 |

完整属性含Python类、Tk类型/路径、父级、变量名/源码位置（能定位时）、屏幕/窗口/父级坐标、实际像素尺寸、布局方式及grid/pack/place参数、支持的CTk颜色/圆角/边框/尺寸/字体等。width/height选项为配置值，实际width/height字段为当前像素几何；属性不可用时不伪造值。颜色元组保留浅/深色两项。

属性窗口是只读快照；要更新，重新悬停或锁定目标，再按Ctrl+Alt+D。关闭属性窗口不会关主程序。检查模式关闭后Tab及点击恢复原行为，卸载仅移除工具自身绑定。

下载卡片是单Canvas绘制，内部封面、复选框、播放图标还不能作为独立Tk控件列属性，本轮不新增虚拟元素识别。检查快捷键不能在其他程序拥有焦点时全局触发。

验证与回滚以根04_交接状态.md为准；不将代码检查当作用户实际显示器的视觉验收。
