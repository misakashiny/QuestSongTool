# AGENTS.md —— AI 开发入口（先读这一页）

> 这是一个 **Windows 桌面 GUI 工具**：对比 PC 本地与 Meta Quest 头显上的 Beat Saber 自定义歌曲。
> 本文件是给 AI 开发者的**最短入口**。深入内容一律去 `docs/00_AI接手指南.md`。

---

## 0. 三条铁律（违反会直接把项目搞坏）

1. **不许在文档里写没验证过的结论。** 凡是"已完成 / 已修复 / 实测通过"，必须有命令输出或数字支撑。
   本项目最高发的缺陷类型就是**「写了但没生效」**（累计 12 次：注释说流式其实没流式、文档说增量其实全量、
   函数写好了没人调用）。**文档会替错误打掩护** —— 所以每个"就这样实现的"都要能被测试或度量证实。
2. **改完代码立刻跑静态检查**：`python tests\static_check.py`（7 项，秒级）。
   它会抓未定义名、未使用 import、后台线程碰 UI、Settings 字段没人读、调用不存在的方法、
   `getattr` 永远取不到、`.ps1` 的 UTF-8 BOM 丢失。
3. **功能不许丢**。这个工具会给用户**真的删设备上的文件**。任何改动都要先回答：
   "这会不会让它删错东西？" 宁可多一次确认，不可少一次护栏。

## 1. 环境与命令（照抄即可）


## 3. 改代码的固定动作

| 你要改什么 | 必须同时做的事 |
|---|---|
| 任何 `.py` | 跑 `python tests\static_check.py` |
| 界面文字 | 加进 `messages.py` 中英**两份**；跑 `smoke_i18n` |
| 配色 / 间距 | 只改 `theme.py`；跑 `theme_contrast.py`（WCAG 对比度会拦住"太白"） |
| 界面版式 | 跑 `scaling_check.py`（它会拦住"控件被挤扁"这类无声坏法） |
| 后台线程 | 只允许 `tasks.emit(...)`，**绝不碰 Tk 控件、绝不 `root.after()`** |
| 复制 / 删除 | 跑 `e2e_core.py` + `e2e_adb.py`；**不许绕过 `workers.py` 里的护栏** |
| `shell_*.ps1` | **必须保存为 UTF-8 with BOM**（编辑工具会静默去掉 BOM，静态检查第 2 项守着） |
| 任何改动 | 跑 `python tests\run_all.py`，必须 **21/21 组通过** |
| 任何改动 | 同步更新 `CHANGELOG.md` + 相关文档（见第 5 节） |

## 4. 测试与验证

```powershell
python tests\run_all.py        # 21 组全跑（必须 21/21）
python tests\static_check.py   # 7 项静态检查
```

`tests\run_all.py` 的 21 组（顺序有理由，不要随意调）：

```
static  未定义名 / BOM / 未使用 import / 线程安全 / Settings 字段
theme   配色对比度与层次分离           cover   封面装饰不留大块补边
diag    卡死诊断（看门狗 / slow / 异常接管）
core    解析 / 缓存 / 对比 / 护栏 / 真实复制删除
adb     假 adb 驱动完整读写删          mtp     Shell CopyHere 镜像
gui     真实窗口驱动整条主流程          unit    解析器 / 数据库 / 设置 / 路径判定
deviceguard 真机护栏（Quest 判据 / 拒绝非 Quest / 未验证退出码 2，离线不碰设备）
startup 启动热点度量（emoji 预热 warm vs cold，独立进程取中位数）
songlist 列表控件     features 新功能     dialogs 对话框   i18n 多语言
wireless 无线调试      duplicates 重复检测  playlist 歌单     audio 试听（会开真声卡）
scaling 高 DPI 三档    shots   截图回归（**会弹窗置顶，故意排最后**）
```

**不在 `run_all` 里的**（需要真机，默认只演练）：

```powershell
python tests\e2e_device_real.py          # 真机读写删，**默认 dry-run**；退出码 0
python tests\e2e_device_real.py --yes    # 真跑（会自动复原歌单；有 Quest 判据护栏）
# ⚠️ v17.9 起退出码语义：0 = 通过 ｜ 1 = 断言失败 ｜ 2 = **什么都没验证**（没设备 / 不是 Quest / 歌单空）
#    不要把 2 当成"验过了"。本机插的是小米平板，跑 --yes 必然是 2。
```

## 6. 千万别做

* 别把 `shell_*.ps1` 存成无 BOM 的 UTF-8（PowerShell 5.1 会按 GBK 解码 → 中文路径乱码 → COM 调用失败）。
* 别在音频回调里调 `device.stop()`（会自锁死，实测挂死 2 分钟）。
* 别在工作线程碰任何 Tk 控件，包括 `root.after()`。
* 别用 `Set-Content -Encoding UTF8` 改 `.py` 文件（Windows PowerShell 5.1 会写入 BOM）。
* 别删 `docs\reference\`（原版代码留档，是"为什么这么改"的唯一证据）。
* 别在没跑 `run_all.py` 的情况下说"改好了"。
* 别只跑一个组就下结论 —— 本项目出现过多次「单独跑绿、混跑才红」的时序问题。
