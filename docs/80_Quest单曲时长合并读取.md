# Quest 单曲时长合并读取

本批落实读取提速方案第一步：将每首缺失时长歌曲的文件大小、音频头部和尾部从 3 次 ADB 往返合并为 1 次。保留原时长解析算法、设备身份/目录/取消/超时护栏；本批不增加并发、不引入时长缓存、不改数据库、下载解压、试听引擎或传输流程。之前的 A/C 界面与目录用途标注保留。

远端命令依次核验规范根、非链接歌曲目录和音频文件，读取大小；只对超过 196608 字节的音频读取 65536 字节头部和 131072 字节尾部。每个读取及最后大小复核前保留路径检查，失败则退出；全程不创建远端临时文件。返回 `QSD1:<size>\n`、固定长度头尾及 11 字节结束标志，最大合法帧 196643 字节。主机按固定偏移切分，音频内出现同样标志不会被误切。

大小前后核验能拒绝已观测到的大小变化，不能排除同大小并发改写，也不能提供文件系统原子快照。原桥接器仍为完整接收后再校验返回长度，并非主机流式接收的硬内存上限。原单命令与整体期限、取消令牌、设备身份复核及只读根白名单保持。
