# 2026-10-28 曲库与歌单改进

本批改动围绕歌曲删除、传输入口、在线搜索、下载页、歌单和任务中心展开，继续使用现有 PySide6 + Qt Widgets，不改数据库结构和 Quest 歌曲内容格式。

## 已完成

- 歌曲列表右键菜单增加“删除歌曲…”，列表获得焦点后按 `Del` 也可触发；确认框支持 `Enter` 确认和 `Esc` 取消。搜索输入框中的 `Del` 仍只编辑文字。
- 本地歌曲进入 Windows 回收站；Quest 歌曲在确认后移到当前歌曲根目录的隐藏隔离区，并保存事务记录。设备、目录或 Info 内容变化时停止处理，不执行永久递归删除。
- 移除“本次启用传输”和“启用歌曲传输”的额外入口，主曲库直接显示“传输到 Quest”“补齐缺失”和传输记录。设备、快照或选曲不满足条件时，按钮禁用并显示原因。
- 下载页默认 6 列 × 8 行，每页最多 48 首；封面加载仍使用有界并发、磁盘缓存和可见项优先。
- 搜索支持歌名、歌手、谱师、BeatSaver 歌曲链接和 `#编号`；搜索与下载共用可用已发布版本选择逻辑，接口异常与没有可用版本分开提示。
- 发现歌单搜索会跳过 BeatSaver 返回的旧格式歌单记录，并在状态栏显示跳过数量；单条异常记录不会再让整页搜索失败。
- 发现歌单使用卡片布局、分类标签、封面缓存和详情页；详情页可以保存歌单到本地歌单并继续使用原下载队列。
- 本地歌单页增加本地歌单 / Quest 3 歌单分区，支持 Quest 歌单读取、本地保存、`.bplist` 导出和向 Quest 发送歌单。
- Quest 歌单目标固定为 `ModData/com.beatgames.beatsaber/Mods/PlaylistManager/Playlists` 的规范 ADB 路径；发送采用暂存、SHA-256 校验和无覆盖发布。歌单只传清单，歌曲文件仍需单独下载和传输。
- 下载任务增加状态徽标、进度条和数量概览，保留原队列、取消、重试和历史记录语义。
