### 怎么验（插上设备后照着做）

```powershell
# 0) 先确认设备可见、路径正确
python -m quest_tool --doctor
python -m quest_tool --scan

# 1) 真机读写删（有 Quest 型号护栏，会自动复原歌单）
python tests\e2e_device_real.py          # 先 dry-run 看它打算做什么
python tests\e2e_device_real.py --yes    # 确认无误再真跑

# 2) 批量复制：界面上选中 50 首 → 「📤 → Quest」，记下耗时与进度百分比
# 3) 无线：界面「📶 无线」→ 选「USB 转无线」→ 连接 → 拔线 → 重新扫描
#    或用配对码（头显：设置 → 系统 → 开发者 → 无线调试 → 使用配对码配对设备）
```

**两个必须记住的点**（界面上也写了）：

1. **配对端口 ≠ 连接端口** —— 连接要用「无线调试」页面上的那个端口，配对码页面上的端口只用于配对；
2. 有些路由器开了「AP 隔离」，同网段设备互相访问不了 —— 这时无线连不上，但插线能用。
